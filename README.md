# 棒球群島 BASEBALL ARCHIPELAGO

把中華職棒 1990–2026 的十四個球團畫成一片群島：浮島、沉島、幽靈島，以及島與島之間的改名、合併、隊名交換與重生。

這不是一張球隊地圖，是一個**本體（ontology）的介面**。島是類別的實例，線是 object property，真正的工作在那些「要不要連、怎麼連」的判斷上。

## 為什麼是球團

球團數量小到一個人做得完，但同一性問題大到足以踩遍本體建模的每個難處：

- 改名算不算同一個東西？（兄弟象 → 中信兄弟）
- 換老闆算不算？（俊國熊 → 興農牛 → 義大犀牛 → 富邦悍將）
- 解散二十年後用同一個名字回來算不算？（味全龍 1999 → 2019）
- 兩支球隊互換名字之後，誰是誰？（2003 年兩聯盟合併案）
- 同一個母企業的兩支球隊該不該連？（中信鯨 ↮ 中信兄弟）

最後一條是本資料集唯一一條 `noRelation`：與其讓這條邊不存在，不如把「不存在」明確寫出來，否則讀者無從分辨是沒資料，還是判定為無關。

## 結構

```
index.html       版面與互動（全景／時間／清單／本體／關於）
franchises.js    資料檔 = 本體實例化後的結果
README.md
```

資料與呈現分離。改資料不必動版面，改版面不必動資料。

### 類別

| Class | 說明 |
|---|---|
| `Franchise` | 球團。經營實體，可跨年、可轉手、可休眠、可被除名 |
| `Team` | 隊名時期。掛在 Franchise 底下，有起訖年 |
| `Event` | 沿革事件：加盟、轉賣、改名、解散、除名、重新加盟 |
| `League` | 中華職棒（1990–）、台灣大聯盟（1997–2002） |
| `Statement` | 預留給來源歧異的情況，目前以頁尾來源清單代行 |

### 關係

`renamedTo`　`succeededBy`　`mergedInto`　`nameSwap`　`revivedAs`　`dissolvedIn`　`expelledIn`　`noRelation`

完整定義與設計決策見網站的「本體」頁。

## 待補

Person（球員、教練）、Venue（球場）、Season、Game 尚未建立。年度總冠軍次數只填寫有把握的球團，其餘留空而不臆測——本體的誠實比完整重要。
